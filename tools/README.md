# StarRocks Profile Analysis Tools

This directory contains tools for analyzing StarRocks query execution profiles to identify performance bottlenecks and generate comprehensive reports.

## Tools Overview

### 1. `extract_slowest_operator.py`

Extracts the slowest operators from StarRocks profile files and provides detailed analysis.

#### Features
- Parses StarRocks pseudo-YAML profile files
- Identifies operators with the highest `OperatorTotalTime`
- Supports top-N operator extraction (default: 1)
- Reorders time metrics within `UniqueMetrics` in descending order
- JSON output mode with simplified operator information
- Time percentage calculation relative to `QueryExecutionWallTime`
- Standardized time units (milliseconds) with 3 decimal places

#### Usage
```bash
# Extract the single slowest operator
python3 extract_slowest_operator.py --input profile_file.profile

# Extract top 5 slowest operators
python3 extract_slowest_operator.py --input profile_file.profile --top 5

# Output in JSON format
python3 extract_slowest_operator.py --input profile_file.profile --json

# Specify output file
python3 extract_slowest_operator.py --input profile_file.profile --output result.json
```

#### Arguments
- `--input`: Input profile file path (required)
- `--output`: Output file path (optional, defaults to stdout)
- `--top N`: Number of top operators to extract (default: 1)
- `--json`: Enable JSON output mode

#### JSON Output Format
```json
{
  "operators": [
    {
      "OperatorName": "HASH_JOIN_PROBE",
      "PlanNodeId": 123,
      "OperatorTotalTime": 1250.456,
      "TimePercent": 45.123,
      "TopMetrics": [
        {
          "MetricName": "AggComputeTime",
          "Value": 800.234,
          "Percent": 28.901
        }
      ]
    }
  ]
}
```

### 2. `summarize_profile_analysis_csv.py`

Aggregates results from multiple JSON outputs generated by `extract_slowest_operator.py` into comprehensive CSV or HTML reports.

#### Features
- Reads multiple JSON files from a directory
- Aggregates metrics by `Operator:MetricName` (sums duplicate entries)
- Shortens file names (e.g., `7321.sql`)
- Supports both CSV and HTML output formats
- Interactive HTML table with sorting and color coding
- Summary statistics (count, sum, geometric mean, arithmetic mean)
- Sticky headers and first column for better navigation

#### Usage
```bash
# Generate CSV report
python3 summarize_profile_analysis_csv.py --input results/profile_analysis/

# Generate HTML report
python3 summarize_profile_analysis_csv.py --input results/profile_analysis/ --format html

# Output only milliseconds values
python3 summarize_profile_analysis_csv.py --input results/profile_analysis/ --value ms

# Output only percentage values
python3 summarize_profile_analysis_csv.py --input results/profile_analysis/ --value percent

# Specify output file
python3 summarize_profile_analysis_csv.py --input results/profile_analysis/ --output summary.html
```

#### Arguments
- `--input`: Directory containing JSON files (required)
- `--output`: Output file path (optional, defaults to stdout)
- `--format`: Output format - `csv` or `html` (default: csv)
- `--value`: Value type - `both`, `ms`, or `percent` (default: both)

#### HTML Features
- **Interactive Sorting**: Click column headers to sort by metric values
- **Color Coding**: Each operator group uses a consistent color scheme with intensity based on values
- **Sticky Navigation**: First column (file names) and top two rows (headers) remain fixed during scrolling
- **Summary Statistics**: Fixed summary rows at the top showing count, sum, geometric mean, and arithmetic mean
- **Responsive Design**: Fixed cell widths with horizontal scrolling for large datasets
- **Hover Tooltips**: Full content display on header hover

## Workflow Example

1. **Extract slowest operators from individual profiles**:
   ```bash
   # Process all profile files
   for profile in benchmark/results/starrocks_profiles/*.profile; do
     python3 extract_slowest_operator.py --input "$profile" --json --output "benchmark/results/profile_analysis/$(basename "$profile").json"
   done
   ```

2. **Generate comprehensive summary report**:
   ```bash
   # Create HTML report
   python3 summarize_profile_analysis_csv.py \
     --input benchmark/results/profile_analysis/ \
     --format html \
     --output benchmark/results/profile_analysis_summary.html
   ```

## Dependencies

- Python 3.6+
- Standard library modules only (no external dependencies)

## Notes

- Profile files use a pseudo-YAML format that requires custom parsing
- Time values are standardized to milliseconds with 3 decimal places
- HTML reports include client-side JavaScript for interactivity
- Summary statistics are calculated using standard mathematical formulas
- Color coding uses HSL color model for consistent visual representation
